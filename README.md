# 🏎️ Redline Horizon

An endless highway racing game built with HTML, CSS and JavaScript.

## 🎮 Play the game

**Live game:** https://bhaiyasingh45.github.io/redline-horizon-game/

## Controls

- **← → / A D** — Steer
- **↓ / S** — Brake
- **Space / Shift** — Nitro
- **P** — Pause
- **M** — Mute / unmute
- **F** — Fullscreen

## About

Redline Horizon is a browser-based endless racing game featuring traffic, near misses, Overdrive, nitro, missions, multiple environments, weather effects, sound effects, mobile controls, and persistent high scores.

## Tech

- HTML
- CSS
- JavaScript
- HTML Canvas
- Web Audio API
- Local Storage

The game runs entirely in the browser with no backend required.
